# Preserved desktop layouts

`classic-light` preserves the previous light desktop from commit `5499720`, including
the separate desktop app row, light Now Playing card, original dock and wallpaper.
`charcoal` preserves the current dark wallpaper, white live desktop lettering,
artwork-backed player with stronger glow, eight-app light dock with softer glow,
and the player moved upward by 24 pixels.

These are reference snapshots for the future theme feature. No theme switcher is
installed by this change. The current Charcoal desktop remains active. Complete
configuration/helper copies preserve each visual baseline for comparison; future
theme switching should apply layout/palette sections while retaining newer bug
fixes and functionality, rather than replacing live scripts wholesale.

Each folder includes its wallpaper, layout metadata and SHA-256 checksums. Personal
dock preferences, media state, account credentials and SSH profiles are excluded.
